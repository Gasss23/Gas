[D1-parola-singola] RISPOSTA FINALE:
Le iterazioni sono cicli che ripetono un blocco di istruzioni più volte finché non viene soddisfatta una condizione.  
In programmazione si usano tipicamente:

* **`for`** – per contare un numero noto di volte (es. da 0 a N‑1).  
* **`while`** – ripete finché una condizione rimane vera.  
* **`do‑while`** – simile a `while`, ma esegue almeno una volta il blocco.  

Esempio in Python:

```python
# for: stampa i numeri da 1 a 5
for i in range(1, 6):
    print(i)

# while: somma i numeri finché la somma è < 20
s = 0
n = 1
while s < 20:
    s += n
    n += 1
print(s)   # 21
```

Le iterazioni sono utili per elaborare collezioni, cercare valori, ripetere operazioni di calcolo, ecc. Se hai un caso specifico o vuoi vedere un esempio in un altro linguaggio, fammi sapere.

## Principi di autonomia di GAS

GAS è un agente AI personale progettato per operare in modo autonomo su VPS.
La filosofia centrale è: robustezza prima della potenza. Un sistema che non crasha
mai vale più di un sistema potente ma instabile.

Il pipeline multi-brain segue una cascata di fallback: Gemini → Groq → OpenRouter
→ Ollama. Ogni provider viene tentato in ordine; se fallisce, si passa al successivo
senza interrompere la sessione. Ogni eccezione viene loggata in gas_debug.log.

## Memoria e conoscenza

GAS distingue tre livelli di memoria:

1. **Diario runtime** (.gas_memory.db, tabella `diario`): eventi append-only generati
   durante le conversazioni. Immutabile: non si cancella, non si modifica. È la
   "scatola nera" del comportamento passato.

2. **Contatti/CRM** (.gas_memory.db, tabella `contatti`): anagrafica mutabile dei lead
   e delle persone con cui GAS interagisce. Lo stato del funnel viene aggiornato tramite
   tool dedicati (`salva_contatto`, `imposta_stato_contatto`).

3. **Knowledge base** (.gas_knowledge.db): conoscenza deliberata ingerita da fonti
   fidate approvate dall'operatore. Separata dal diario per mantenere isolamento tra
   memoria runtime e conoscenza statica.

difesa contro loop infiniti che consumerebbero il budget API.

Le **iterazioni** sono i cicli che ripetono un blocco di istruzioni finché una condizione è soddisfatta. In programmazione si realizzano principalmente con:

| Costrutto | Linguaggio tipico | Quando usarlo |
|-----------|-------------------|----------------|
| `for`     | Python, C, Java   | Quando conosci il numero esatto di ripetizioni o iteri su una sequenza (lista, range, ecc.). |
| `while`   | Python, C, Java   | Quando la condizione di terminazione dipende da un valore che cambia all’interno del ciclo e non è noto a priori. |
| `do‑while`| C, Java, JavaScript| Simile al `while`, ma garantisce almeno un’esecuzione prima del controllo della condizione. |

Esempio in Python (iterare da 1 a 5):

```python
for i in range(1, 6):
    print(i)
```

Esempio in Python (while, somma finché < 100):

```python
s = 0
n = 1
while s < 100:
    s += n
    n += 1
print(s, n)
```

Le iterazioni sono fondamentali per:
- Elaborare collezioni di dati.
- Ripetere calcoli finché si raggiunge una precisione desiderata.
- Implementare algoritmi ricorsivi in forma iterativa per migliorare l’efficienza di memoria.

Se hai uno specifico caso d’uso o vuoi vedere il codice in un linguaggio diverso, fammi sapere!
