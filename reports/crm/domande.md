# CRM — domande aperte per l'operatore

> Si risponde man mano; la risposta finisce in `decisioni.md` e qui la domanda si toglie.

1. **Servizi e commissioni.** Per calcolare quanto ci rende ogni cliente e quanto vale ogni proposta, il CRM deve sapere, per ogni servizio, come vi pagano: una percentuale sui profitti del cliente (es. 20%), una percentuale all'anno sul capitale (es. 2%), oppure un abbonamento fisso (es. 99 € al mese). Più il capitale minimo per entrare. Servono per i 4 servizi (rendimento contrattuale, matched trading, copy trading algoritmico, il quarto) e per la sala segnali / copyflip.
2. **WhatsApp Business: app o API?** Per l'invio davvero automatico serve l'accesso API (piattaforma di Meta per sviluppatori), non solo l'app sul telefono. Ce l'hai, o va attivato?
3. **Modello del cervello forte in chat.** Quando parli a Gas di un cliente, il messaggio va al cervello forte, che oggi è Sonnet. Vuoi Opus anche lì (consuma di più dell'abbonamento)? Basta una riga nel file delle chiavi.
4. **Collegare le chat fra loro.** Le sessioni di Claude Code non si parlano da sole: condividono solo il repo. Vuoi una bacheca comune (un file in `reports/` che ogni chat legge all'inizio e aggiorna quando scopre un problema), più un messaggio diretto alle altre sessioni quando succede qualcosa di grave?
