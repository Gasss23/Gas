# Website service showcase

Use this workflow for service or professional sites whose main goal is to start conversations with prospective customers.

## Workflow

1. Open the supplied URL. Inspect its content, navigation, forms, and contact path. Check whether editable source exists; distinguish the public domain, site builder, hosting, and local preview.
2. Identify the audience, services, desired action, and details the user wants to keep private. If facts are missing, keep public copy accurate and direct specifics to a conversation.
3. Keep the page focused: clear hero, concise service routes, and one repeated contact action. Add social proof only when requested; never invent endorsements, guarantees, credentials, or returns.
4. Design for mobile first. Avoid decorative trading screens and charts unless requested. If using 3D, choose one meaningful object and prefer real WebGL geometry, lighting, shadows, depth, reduced-motion support, and movement tied smoothly to scroll.
5. If the user requests many visual alternatives, produce a contact sheet of about 20 distinct concepts, rank them against the brief, and implement the strongest. If they select another, follow their choice. Do not build 20 unfinished pages.
6. Make every primary CTA use the user's stated contact channel. For WhatsApp, use the supplied number in an international `wa.me` link and a short prefilled message the visitor reviews and sends.
7. If source access exists, edit and preview the project. Otherwise save a standalone preview with its required assets and state that the live site is unchanged. Never imply a preview has been deployed.
8. Before publishing, get the user's review when requested, verify the contact path and mobile layout, and report the preview path, deployment state, checks performed, and any missing access or evidence.

## Copy pattern

- Hero: one clear value statement, brief orientation, one primary contact action.
- Services: name each offer and say what the visitor can ask about; omit unprovided terms and percentages.
- Trust: use authentic, authorized evidence or clearly labelled illustrative examples.
- Close: repeat the contact action and explain what the first conversation can cover.
